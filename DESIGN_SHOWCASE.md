```

  ↓

  ↓

  ↓

  ↓

  ↓

```

## ⚡ Animation Examples

### Fade In (Loading)
```
Component appears with opacity:
0% opacity → 100% opacity (300ms)
```

### Slide In (Sidebar)
```
Component slides from left:
-20px → 0px (300ms)
```

### Hover Effects
```
Cards:     Lift up 4px, enhanced shadow
Buttons:   Darken background, slight lift
Links:     Underline appears, color changes
```

### Pulse (Loading)
```
Breathing animation:
100% opacity ↔ 50% opacity (2s infinite)
```
