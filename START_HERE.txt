🚀 QUICK START (3 STEPS)
════════════════════════════════════════════════════════════════════════════

1. START BACKEND
   ──────────────
   cd server
   npm install
   cp .env.example .env
   npm run dev
   → Server runs on http://localhost:5000

2. START FRONTEND
   ───────────────
   cd client
   npm install
   npm run dev
   → Frontend runs on http://localhost:3000

3. START ADMIN
   ────────────
   cd admin
   npm install
   npm run dev
   → Admin runs on http://localhost:3001

✅ You're ready to go!
